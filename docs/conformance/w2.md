# Conformance rows: JSEP, codec negotiation, API state rules (W2)

Rows for `docs/conformance.md`. Each names the spec section, where it is implemented and the
test that proves it.

## Not implemented / limits

| Area | What | Why |
|---|---|---|
| W3C stop() | No separate "stopping" state: `stop()` makes a transceiver stopped at once; negotiation-needed treats it as stopping until its m= section is rejected in both descriptions | The sans-I/O transceiver has one stopped flag; the observable negotiation follows the spec |
| addTransceiver(track) | A non-sending direction with a track is refused (`ErrInvalidDirection`) | Not changed in this stream |
| Rejected remote m= sections | The application stops its own transceiver (the engine doesn't stop it for a rejected section in a remote offer) | Kept from wpt100's design |
