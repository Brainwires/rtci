## Not implemented (claim removed or never made)

| Area | Not implemented | Note |
|---|---|---|
| FlexFEC (RFC 8627) | Answering FlexFEC only when it is offered with RTX (1.1.7); refusing an offer whose `repair-window` cannot be supported (5.2.1); SR / SDES for the repair SSRC (4.2.1); loss-driven adaptation of the amount of FEC (8); in-band SSRC mapping in the engine (7.1.1; the interceptor has it); `audio/`, `text/` and `application/flexfec` | The coder is opt-in (`FlexFecSendBuilder`, `FlexFecReceiveBuilder`) and `video/flexfec` is not a default codec |
| FEC | ULPFEC in a separate RTP session (RFC 5109 14.1, `a=group:FEC`) | ULPFEC is implemented in RED and on a repair SSRC, opt-in, and is not in the default codecs (D1); the engine has one RTP session |
| VP8 payloader | Partition-aware packetization (one partition per packet, `PID` counted) | The frame is cut at MTU boundaries with `PID` 0, which RFC 7741 4.4 allows |
| SVC | `scalabilityMode` on an encoding, its validation and its statistic; offering the Dependency Descriptor extension by default | `rtc-rtp` has the modes, their structures and the wire signalling; the peer connection does not use them yet |
| RTP | A DTMF sender, RED and comfort noise in the engine | `rtc-rtp` has the payload formats and state machines; nothing in the engine offers them, paces DTMF packets or wraps audio in RED (the opt-in ULPFEC interceptors carry video FEC in RED) |
| H.264 | `packetization-mode=2` (interleaved) in negotiation | The payloader and the depacketizer implement it; no default codec offers it, and the SDP parameters of the de-interleaving buffer are not read |
| VP9 payloader | Intra-only (non-key) frames are sent with `P=1` | The uncompressed header's `intra_only` is not read |
