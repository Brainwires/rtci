## Not implemented (claim removed or never made)

| Area | Not implemented | Note |
|---|---|---|
| RTP | A DTMF sender, RED and comfort noise in the engine | `rtc-rtp` has the payload formats and state machines; nothing in the engine offers them, paces DTMF packets or wraps media in RED |
| FEC | RFC 8627 FlexFEC, ULPFEC (RFC 5109) | ULPFEC is not in the default codecs (D1); `video/flexfec` never selects the draft-03 coder |
| H.264 | `packetization-mode=2` (interleaved) in negotiation | The payloader and the depacketizer implement it; no default codec offers it, and the SDP parameters of the de-interleaving buffer are not read |
| VP9 payloader | Intra-only (non-key) frames are sent with `P=1` | The uncompressed header's `intra_only` is not read |
