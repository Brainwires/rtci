Deliberate, for the owner: `use_srtp` is offered on every association by default although RFC
5764 §4.1 reserves it for RTP (browsers do the same; `with_disable_dtls_use_srtp` gives the RFC's
behaviour). Lower-case hex in a received fingerprint is accepted. A sha-1 fingerprint is accepted
when the peer offers nothing stronger (RFC 8122 still defines it and browsers accept it) and
never produced.
