# Conformance rows: statistics (W5)

Rows for `docs/conformance.md`. Each names the spec section, where it is implemented and the
test that proves it. The report is the engine's claim: a member it emits is a member it
measures, and a member it cannot measure is left out (webrtc-stats: a member the
implementation does not measure is not present), not reported as 0.

## Not implemented / limits

| Area | What | Why |
|---|---|---|
| ECN without the socket layer | `packetsReceivedWithEct1`, `packetsReceivedWithCe` (inbound), `packetsSentWithEct1` absent unless `SettingEngineBuilder::with_ecn` is on | The engine cannot see the IP header; only an application whose socket layer reads and sets the codepoint can measure them |
| RFC 8888 without `ack ccfb` | `packetsReportedAsLost`, `packetsReportedAsLostButRecovered`, remote-inbound ECN counts and `packetsWithBleachedEct1Marking` absent | They come from RFC 8888 reports, which a stream without `ack ccfb` negotiated does not have (TWCC carries no ECN) |
| `totalPacketSendDelay` | Absent | The engine has no pacer: it sends what it is given at once |
| `estimatedPlayoutTimestamp`, corruption, PSNR, `qualityLimitationDurations` | Absent | They need a playout clock or an encoder / decoder; no feed carries them |
| `dataChannelIdentifier` | 0 until the SCTP stream id is assigned | Kept as an integer for API compatibility |
