# RFC 5583: Signaling Media Decoding Dependency in SDP: clause audit

Spec: RFC 5583, July 2009, as RFC 7798 section 7.2.5 uses it for H.265 MRST / MRMT. Audited
and implemented at `conf/jsep-47-depend` (jsep11).

`a=depend` is `sdp::attribute::Depend` (`rtc-sdp/src/attribute/grouping.rs`); a remote
description's DDP groups and dependencies are `RTCPeerConnection::remote_decoding_dependencies`,
the hook a receiver of layered media reads; an answer keeps the offered relations for what it
accepts (`answer_decoding_dependencies`). The engine offers no DDP group itself: it neither
produces layered streams nor has an API to declare them (the media side owns that).
