# RFC 8261: Datagram Transport Layer Security (DTLS) Encapsulation of SCTP Packets

Spec: RFC 8261, November 2017 (updated by RFC 8899 and RFC 8996; references RFC 4960, which
RFC 9260 obsoletes). Audited against fork master 8916bc3. Scope: an endpoint running one SCTP
association over one DTLS transport. Rows whose level is marked `(implicit)` paraphrase required
behaviour the RFC states without a BCP 14 keyword; they are counted under the level shown.

`conf/datachannel-2-sctp-wiring`; the other rows are `rtc-sctp`'s and `rtc-dtls`'s.

## Gaps, in order of importance

State: gap 2 is closed (5-8: the packet size follows the selected path, 1200 bytes at the IP
layer over IPv4). Of gap 1 the path-change entry is there and wired to ICE (6.1-7, `partial`);
probing is not (4-1, 4-2, 6.2-1).

1. **Path MTU discovery (4-1, 4-2, 6.2-1, 6.1-7), size L.** Implement DPLPMTUD (RFC 8899, which
   updates this RFC) in `rtc-sctp`: PAD chunk (RFC 4820) encode/decode, HEARTBEAT+PAD probes, a
   probe state machine with its timer in `poll_timeout`, the effective MTU feeding
   `max_payload_size`, plus an `Association::on_path_change()` entry the ICE handler calls when
   the selected pair changes (resets cwnd/ssthresh and restarts probing). Black-hole detection
   falls out of the same machine.
2. **Safe default MTU (5-8), size S.** Until PMTUD exists, either lower the default so the IP
   packet stays within 1200 bytes (SCTP packet <= 1200 - 20 - 8 - 37 = 1135 on IPv4) or record
   the 1280 choice as a decision in `docs/conformance.md`. With PMTUD the base value becomes
   the probe floor and this closes itself.
3. **DTLS versions (5-1, 5-2), size XL / decision.** DTLS 1.0 is deprecated by RFC 8996: record
   the clause as superseded rather than implement it. DTLS 1.3 is the real work and belongs to
   the DTLS area.
4. **Negative tests for INIT content and DTLS compression (6.1-4, 6.1-5, 5-3), size S.** One
   `rtc-sctp` test that parses a generated INIT and INIT ACK and asserts the parameter types;
   one `rtc-dtls` test that offers a non-null compression method and asserts null is chosen.
5. **ECN (5-10), size L.** Optional; needs the lower layer to surface ECN bits, ECN-capable
   negotiation, ECNE/CWR.
6. **Optional extensions (6.1-2, 6.4-1, 6.6-2, 6.7-1), size L each.** Multiple associations,
   SCTP-AUTH, Add Streams, I-DATA: optional here; I-DATA and Add Streams are tracked in the
   RFC 8260 and RFC 6525 audits.

## Bugs found

None that is a defect of existing behaviour. 5-8 is a documented design choice that contradicts
a SHOULD: to observe it, send a 64 KiB message over an IPv4 path and capture the UDP datagrams;
IP total length is 1256, above the 1200 the RFC recommends when DF cannot be set.
