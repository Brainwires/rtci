# RFC 7728: RTP Stream Pause and Resume: clause audit

Spec: RFC 7728, February 2016. Audited and implemented at `conf/jsep-46-pause-resume` (jsep11).

The PAUSE-RESUME message (RTPFB, FMT 9) is `rtcp::transport_feedbacks::pause_resume`; both roles
run in `PauseResumeInterceptor` (`rtci-interceptor/src/pause_resume/`) at `Slot::PauseResume`,
installed with `configure_pause_resume` (not part of the default interceptors: no browser
implements RFC 7728), which also offers `a=rtcp-fb:<pt> ccm pause`. The application asks for
pauses and resumes, pauses its own streams and reads their states through `PauseResumeHandle`;
every PAUSE-RESUME message read is also delivered to it. Sections 1 to 5 are descriptive; the
rows start with the states of section 6. Section 9.2 (declarative SDP) does not apply to an
offer/answer endpoint. Section 10 is examples.
