# RFC 9147 conformance audit: Datagram Transport Layer Security version 1.3

Spec: RFC 9147, April 2022 (obsoletes RFC 6347). Audited at feature granularity per section, as asked: one row stands for the clauses its note counts.

Audited at fork master 8916bc3. No part of DTLS 1.3 is implemented: no supported_versions, key_share, HKDF key schedule, unified header, ACK or KeyUpdate anywhere in `rtc-dtls` (`grep -riE "supported_versions|key_update|0xfefc" rtc-dtls src` finds nothing). The stack speaks DTLS 1.2 (RFC 6347), which RFC 9147 obsoletes but does not forbid. `docs/conformance.md` lists DTLS 1.3 under "Not implemented, on purpose"; every row is still `missing` and counted. All sections (4 to 13) covered.

## Gaps, in order of importance

1. **DTLS 1.3 (XL).** Everything in the table is one decision: implement RFC 9147 on top of a TLS 1.3
   handshake (RFC 8446 key schedule, HKDF, the new flights), the unified record header with
   sequence-number encryption, ACK, KeyUpdate and the AEAD limit counters. Rough split:
   record layer and epochs (L), handshake and key schedule (XL), ACK and retransmission (L), KeyUpdate
   and limits (M), CID messages (M, needs RFC 9146 groundwork), version negotiation with DTLS 1.2
   fallback and downgrade sentinel (M). Browsers are moving to DTLS 1.3 for WebRTC and still
   accept 1.2 (from memory, not checked here), so nothing breaks without it; "all of the WebRTC specification set" (RFC 8827 6.5
   requires 1.2 only) does not strictly need it. `docs/conformance.md` lists it under "Not
   implemented, on purpose".
2. **Pin the fallback (S).** RFC9147-5.3-2: a test that feeds a real DTLS 1.3 ClientHello
   (supported_versions, key_share, TLS 1.3 suites, 0xfefd legacy version) and expects a DTLS 1.2
   ServerHello. This is what a DTLS 1.3-capable peer sends first.
3. **Carry over to DTLS 1.2 now (S each).** Three rules of RFC 9147 are worth applying to the 1.2
   path regardless: the 400 ms / 1.5 x RTT timer guidance for DTLS-SRTP (5.8.2; the ICE round trip
   is known), the three-times amplification bound (5.1), and counting authentication failures per
   key (4.5.3).

## Bugs found

None: there is no DTLS 1.3 code. Bugs in the shared DTLS 1.2 machinery are in `rfc6347.md` and `rfc5246.md`.
