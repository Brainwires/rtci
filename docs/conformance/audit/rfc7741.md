# RFC 7741: RTP Payload Format for VP8 Video

Spec: RFC 7741, March 2016 (Standards Track). Audited against fork master 8916bc3.
Sections covered: 4 (payload format), 5 (RPSI/SLI), 6 (parameters, SDP), 7, 8. All normative text.

Code: `rtc-rtp/src/codec/vp8/mod.rs` (`Vp8Payloader`, `Vp8Packet`), tests in
`rtc-rtp/src/codec/vp8/vp8_test.rs`; frame assembly in `rtc-media/src/io/sample_builder/mod.rs`;
negotiation in `src/rtp_transceiver/fmtp/generic/mod.rs` and
`src/peer_connection/configuration/media_engine.rs`.

The payloader emits the mandatory descriptor octet, plus X/I/PictureID when `enable_picture_id` is
set (the peer connection sets it, `rtp_codec.rs:107`). It never emits L, T, K, TL0PICIDX, TID, Y or
KEYIDX: those describe temporal layers, which only the encoder knows, and the `Payloader` trait
gives no way to pass them in. Clauses about their values on the send side are therefore `missing`
as a feature (temporal scalability cannot be signalled), and clauses about the encoder's reference
structure are `n/a`.

## Status after the VP8 work (branch `conf/vpx-av1-svc-1`)

Gaps 1, 2, 3 and 6 below are closed and Bugs 1 to 4 are fixed, each with the tests named in the
table. Still open: gap 4 (partition-aware packetization: RFC7741-4-1, 4.2-7, 4.2-11, 4.4-4), gap 5
(`max-fs` / `max-fr`: 6.1-1, 6.1-2, 6.2.2-1), gap 7 (RPSI), and congestion control (8-1).

## Gaps, in order of importance

1. **Depacketizer correctness (S).** RFC7741-4.2-15, -20, -21, -38, 4.5-2: reset all fields at the
   start of `depacketize`; accept any packet with at least one data octet after the descriptor
   (compute the descriptor length, then require `len > descriptor`).
2. **Frame start detection (S).** RFC7741-4.5-1: `is_partition_head` is `S == 1 && PID == 0`.
3. **Temporal layers on send (M).** RFC7741-4.2-37, -6: inputs on `Vp8Payloader` (or a
   per-frame descriptor argument on the `Payloader` trait) for N, TL0PICIDX, TID, Y, KEYIDX.
4. **Partition-aware packetization (M).** RFC7741-4-1, 4.2-7, 4.2-11, 4.4-4: read the first
   partition size and the partition count from the frame header, start each partition in a new
   packet, set S and PID.
5. **`max-fs` / `max-fr` (S).** RFC7741-6.1-1, 6.1-2, 6.2.2-1: parse them, expose the remote's
   values on the sender's parameters, and exclude them from fmtp matching.
6. **Random initial PictureID (S).** RFC7741-4.2-25, with tests for the 7/15-bit boundary and the
   wrap (4.2-27).
7. RPSI (S, optional). RFC7741-5.1-1.

## Bugs found

1. **Stale descriptor state between packets.** `rtc-rtp/src/codec/vp8/mod.rs:150-157`: `i`, `l`,
   `t`, `k` (and `picture_id`, `tid`, `y`, `key_idx`) survive from the previous call. Reproduce:
   one `Vp8Packet`; depacketize `[0x90, 0x80, 0x05, 0xAA, 0xBB]` (X=1, I=1), then
   `[0x00, 0x11, 0x22, 0x33, 0x44]` (X=0). Expected payload `[0x11, 0x22, 0x33, 0x44]`; the code
   treats `0x11` as a PictureID octet and returns `[0x22, 0x33, 0x44]`. `SampleBuilder` holds one depacketizer per stream
   (`sample_builder/mod.rs:27`), so this corrupts frames from a sender that mixes X=0 and X=1
   packets.
2. **Short packets refused.** `vp8/mod.rs:136-139` (`payload_len < 4`). Reproduce: depacketize
   `[0x00, 0xAB]` or `[0x00, 0xAB, 0xCD]`: valid continuation packets, `ErrShortPacket` today. The
   fork's own payloader produces such packets: `test_vp8_payload` "WithoutPictureID" emits
   `[0x10, 0x90]`, which `Vp8Packet::depacketize` cannot read back.
3. **A later partition is taken for the start of a frame.** `vp8/mod.rs:207-213`;
   `SampleBuilder` uses `is_partition_head` to decide that a run of packets begins a frame
   (`rtc-media/src/io/sample_builder/mod.rs:306`). Reproduce: a frame sent as three packets with
   one timestamp, `S=1,PID=0`, `S=1,PID=1`, `S=1,PID=2 + marker` (the RECOMMENDED packetization,
   RFC 7741 4.6.3); drop the first and push the other two after a complete earlier frame. The
   builder should emit nothing for that timestamp; with `S` alone as the test it emits a sample
   that lacks the first partition (the frame header).
4. **The payloader and the depacketizer disagree on minimum size** (same root as 2): a
   round-trip property test (payload at MTU 2 to 8, depacketize every packet, concatenate) fails
   for any frame whose last fragment is 1 or 2 octets.
