# RFC 7714 — AES-GCM Authenticated Encryption in SRTP: clause audit

Spec: RFC 7714, December 2015 (current). Audited against fork master 8916bc3. Scope:
`rtc-srtp/src/cipher/cipher_aead_aes_gcm.rs`, `rtc-srtp/src/context/`, the AEAD provider trait in
`rtc-crypto/`, profile wiring in `src/peer_connection/handler/dtls.rs` and
`src/peer_connection/transport/dtls/mod.rs`. Read-only audit; no test was run. SHALL / REQUIRED count
as MUST; RECOMMENDED / NOT RECOMMENDED as SHOULD. Sections 14.1 (SDES), 14.3 and 15 (MIKEY) do not
bind a DTLS-SRTP endpoint and are one row.

## Gaps, in order of importance

1. **SRTCP index wrap reuses GCM nonces (S)** — 9.4-1, 10-4, 13.1-6, 13.1-7, 12-2. Nonce reuse under
   GCM breaks authentication for the key. Stop at 2^31-1 (same fix as RFC 3711 gap 1).
2. **Known-answer coverage (S)** — 11-2, 16-1, 10-1. Add the RFC 7714 §16 and §17 vectors (128 and 256);
   today AEAD_AES_256_GCM, which is in the default offer, is only round-trip tested.
3. **Unencrypted SRTCP under GCM (S)** — 9.3-1 (receive), 9-2 (send, optional). Read the E flag from the
   trailer, build the AD accordingly and skip decryption; §17.3 / §17.4 vectors as tests.
4. **Key and salt erasure (S)** — 13.1-1, 13.1-2, 13.1-3. `SecretVec` for `SessionKeys` and the session
   salts; no `Debug` of key bytes.
5. **Re-key or terminate at the SRTP limit, receiver side included (M)** — 8.4-1, 13.1-6. Same work
   package as RFC 3711 gap 2.
6. **Provider-level AEAD properties (S)** — 5.3-2, 13.1-4. A conformance check in `rtc-crypto` that
   `open_in_place` leaves the buffer unreadable (or unchanged) on a bad tag for every provider.
7. **RFC 6904 keystream for GCM (M, depends on RFC 6904)** — 8.3-1, 8.3-2, 8.3-3.
8. **MKI (on purpose)** — 8.2-3.

## Bugs found

- **SRTCP nonce reuse after 2^31 packets** (`rtc-srtp/src/context/srtcp.rs:69-72`). Reproduction: GCM
  context, `set_index(ssrc, 0x7FFF_FFFF)` (crate test), `encrypt_rtcp` twice with the same input: the
  first call yields index 0 instead of an error; continuing reaches indices already used with this key.
- **A valid unencrypted (E=0) AEAD SRTCP packet is rejected** (`cipher_aead_aes_gcm.rs:181, 345`).
  Reproduction: decrypt the RFC 7714 §17.4 packet (AEAD_AES_256_GCM tag verification, E=0) with the
  section's key and salt: expected the plain RTCP packet, got `ErrFailedToVerifyAuthTag`.
