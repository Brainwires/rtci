# Clause audit: RFC 6458 (partial delivery only)

Spec: RFC 6458, Sockets API Extensions for SCTP, December 2011 (Informational). The engine has no
sockets API, so only the clauses that say what partial delivery (RFC 9260 section 6.9) looks like
to the receiving application are audited here, against `Stream::read_part` (sctp-15). The text
was fetched from rfc-editor.org (it is not among `specs/`). None of these sentences carries an
RFC 2119 keyword: every row is a procedure step ("DESC"). Code paths are relative to
`rtc-sctp/src/`.
