# RFC 8083: Multimedia Congestion Control: Circuit Breakers for Unicast RTP Sessions

Spec: RFC 8083, March 2017 (Standards Track; updates RFC 3550). Sections covered: 3 (the definitions
that carry a requirement), 4, 4.1 to 4.5, 5, 6, 7, 8. Sections 1, 2, 9 to 11 hold no requirement on an
endpoint. RFC 8834 section 7.1 makes the circuit breaker mandatory for a WebRTC endpoint.

Code: `rtci-interceptor/src/circuit_breaker/mod.rs` (`CircuitBreakerInterceptor`,
`CircuitBreakerBuilder`, `CircuitBreakerHandle`), placed at `Slot::CircuitBreaker` (2_500: below the
pacer, above the TWCC sender and the send history) by `register_default_interceptors`. `cb/` abbreviates
that file; tests are in `rtci-interceptor/tests/circuit_breaker.rs` unless a file is named.

"(implied)" marks a requirement the RFC states without a BCP 14 keyword (a formula, "is calculated").
