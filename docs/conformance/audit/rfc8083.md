# RFC 8083: Multimedia Congestion Control: Circuit Breakers for Unicast RTP Sessions

Spec: RFC 8083, March 2017 (Standards Track; updates RFC 3550). Sections covered: 3 (the definitions
that carry a requirement), 4, 4.1 to 4.5, 5, 6, 7, 8. Sections 1, 2, 9 to 11 hold no requirement on an
endpoint. RFC 8834 section 7.1 makes the circuit breaker mandatory for a WebRTC endpoint.

Code: `rtc-interceptor/src/circuit_breaker/mod.rs` (`CircuitBreakerInterceptor`,
`CircuitBreakerBuilder`, `CircuitBreakerHandle`), placed at `Slot::CircuitBreaker` (2_500: below the
pacer, above the TWCC sender and the send history) by `register_default_interceptors`. `cb/` abbreviates
that file; tests are in `rtc-interceptor/tests/circuit_breaker.rs` unless a file is named.

"(implied)" marks a requirement the RFC states without a BCP 14 keyword (a formula, "is calculated").

Totals (MUST includes MUST NOT/SHALL; SHOULD includes SHOULD NOT/RECOMMENDED):

- SHOULD: tested 14 / untested 0 / partial 0 / missing 0 / violated 0 / n-a 3

Section 3: "If the RTP packets being sent vary in size, then the average size over the packet comprising the last 4 * G frames MUST be used"; section 4.3 only adds "the packet size, s, is known to the sender". The default takes s = (bytes sent) / (packets sent) over the last CB_INTERVAL reporting intervals, the window the sending rate is measured over; the RFC form is `PacketSize::LastFrames`. Measured: for speech (750-byte frames in talkspurts, 23-byte silence frames) the last four frames are often silence, s is then 23 bytes against the talkspurts' rate, and the literal form ceases a talking call at 1 to 5 % loss. cb-2 sweep, speech flow, 60 s each, reordering 0/10/40/100 ms x loss 0/1/2/5/20/30 %: under `LastFrames` it ceased at 1 % (40 ms: 10.9 s; 100 ms: 1.5 s), 2 % (100 ms: 12.0 s), 5 % (40 ms: 4.7 s; 100 ms: 3.8 s) and at 20 and 30 % at every reordering; under the default it ceased in none of the 120 cells of five flows (the pacer holds the wire rate to the congestion controller's target, 100 kbit/s at 20 to 30 % loss, so no flow on the wire is ten times TCP). Constant-size flows are unchanged (both forms give the same s) |
