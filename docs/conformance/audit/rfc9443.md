read: `src/peer_connection/handler/demuxer.rs`, `src/peer_connection/handler/ice.rs`,

## Gaps, in order of importance

1. **Explicit drop and a 256-value table test (S).** Same work package as RFC 7983 gap 1; it
   closes RFC9443-3-2 and 3-8.
2. **QUIC multiplexing (XL, not planned).** RFC9443-3-7 only matters if a QUIC transport is ever
   added to the engine.
