# W3C WebRTC Statistics (webrtc-stats): clause-level audit

Spec: Identifiers for WebRTC's Statistics API, W3C Editor's Draft at https://w3c.github.io/webrtc-stats/ (served copy last modified 8 October 2026). Engine: fork master 8916bc3. Rows this branch changed (`conf/stats-conformance`) carry its code references and tests; the others still refer to 8916bc3.

Section numbers are derived from the heading order of the editor's draft: 1 Introduction, 2 Conformance, 3 Terminology, 4 Basic concepts (4.1 design guidelines, 4.2 implementation guidelines, 4.3 lifetime, 4.4 caching), 5 Maintenance, 6 Privacy (6.1 hardware capabilities), 7 RTCStatsType (7.1 enum), 8 Stats dictionaries (8.1 hierarchy, 8.2 RTCRtpStreamStats, 8.3 RTCCodecStats, 8.4 RTCReceivedRtpStreamStats, 8.5 RTCInboundRtpStreamStats, 8.6 RTCRemoteInboundRtpStreamStats, 8.7 RTCSentRtpStreamStats, 8.8 RTCOutboundRtpStreamStats, 8.9 RTCQualityLimitationReason, 8.10 RTCRemoteOutboundRtpStreamStats, 8.11 RTCMediaSourceStats, 8.12 RTCAudioSourceStats, 8.13 RTCVideoSourceStats, 8.14 RTCAudioPlayoutStats, 8.15 RTCPeerConnectionStats, 8.16 RTCDataChannelStats, 8.17 RTCTransportStats, 8.18 RTCDtlsRole, 8.19 RTCIceCandidateStats, 8.20 RTCIceCandidatePairStats, 8.21 RTCStatsIceCandidatePairState, 8.22 RTCCertificateStats), 9 Examples, 10 Security and privacy.

How members were judged. The Note column of every member row starts with one of: `measured` (the engine computes it from its own traffic), `app feed` (present only when the application supplies it through `src/statistics/feed.rs`; the right design for an engine with no encoder, decoder, capture or playout), `absent` (never in the report). `tested` needs a test that asserts the value, not only that the report serializes: most RTP counters have a unit test on the accumulator method but no test that asserts the value the handlers feed it, and are `untested` with that said. An absent member is `missing` even when `docs/conformance/w5.md` lists it as left out on purpose.

## Bugs found

1. **`remoteTimestamp` is the local clock.** `on_rtcp_sr_received` (`src/statistics/accumulator/rtp_stream/inbound.rs:184`) stores `now`; `rtcp_reports.rs:68` never passes `sr.ntp_time`. Reproduce: feed an SR whose NTP time is one hour ahead of `now` through `on_rtcp_received`; the remote-outbound `remoteTimestamp` equals `now`.
2. **`active` is always true.** Set at `accumulator/mod.rs:621` and never written again. Reproduce: negotiate a sender, `set_parameters` with `active: false`, call `get_stats`: the outbound stream still says `"active":true` while its packet counters stay frozen.
3. **`dataChannelsClosed` counts channels that never opened.** `handler/datachannel.rs:696` (handshake timeout) and `announce_closed` (`:107`) count unconditionally. Reproduce: create a channel toward a peer that never answers the DCEP open, run past the handshake deadline: `dataChannelsOpened` 0, `dataChannelsClosed` 1, so opened minus closed is negative.
4. **A remote peer-reflexive candidate's address is exposed.** `update_ice_agent_stats` (`internal.rs:1910`) registers candidates learned from checks with their address. Reproduce: connect two peers, signalling no candidates from one side; the other side's `remote-candidate` of type `prflx` has a non-null `address`.
5. **`firCount` / `pliCount` on audio streams, `retransmitted*Received` without RTX.** Plain `u32` / `u64` fields with no skip rule. Reproduce: an audio-only call without RTX; the inbound-rtp JSON contains `"firCount":0`, `"pliCount":0`, `"retransmittedPacketsReceived":0`.
6. **Padding-only RTX probes count as retransmissions.** `handler/interceptor.rs:997` counts before de-encapsulation decides there is nothing to recover (`endpoint.rs`, "RTX packet with no OSN header"). Reproduce: send an RTX packet with an empty payload; `retransmittedPacketsReceived` becomes 1.
7. **`packetsSent` excludes RTX retransmissions; no-RTX retransmissions are not counted as retransmitted.** `handler/interceptor.rs:1108-1116`. Reproduce: lose a packet with RTX negotiated: `retransmittedPacketsSent` 1 while `packetsSent` did not move; repeat without RTX: `packetsSent` moves, `retransmittedPacketsSent` stays 0.
8. **A recycled SSRC gets the old stats id.** `inbound_stats_id` / `outbound_stats_id`. Reproduce: bind SSRC X, retire it by renegotiation, bind X again: the new object has the id of the deleted one.
9. **Transport `bytesSent` / `bytesReceived` include STUN.** `handler/demuxer.rs:85,137` count every datagram. Reproduce: an idle connected pair with only consent checks flowing: transport bytes grow.
10. **`bytesDiscardedOnSend` is a `u32`** (`accumulator/ice_candidate_pair.rs:58`): wraps at 4 GiB where the member is 64-bit. Unreachable today (nothing feeds it), wrong as soon as something does.
